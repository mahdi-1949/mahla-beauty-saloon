# Mahla Atelier

Persian RTL beauty studio portfolio. 19 independent static pages share assets/site.css and assets/site.js. Serve the root with any static server, or publish it directly with GitHub Pages.

Features: responsive editorial design, illustrated mega menu, service pages, bridal chapter, stock inspiration gallery with category filters and native dialog image viewer, searchable FAQ, three-step demonstration booking and contact form. No personal data is sent or stored. Existing hash links are migrated to independent HTML pages.

Stock photographs are illustrative, not real salon work or staff.
